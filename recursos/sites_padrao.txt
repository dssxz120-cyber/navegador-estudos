# ================================================================
#  Como funciona cada tipo de linha:
#
#    [Nome da categoria]      -> começa um grupo na página inicial
#    Nome | https://endereço  -> cria um atalho E libera o site
#    + dominio.com            -> libera o domínio sem criar atalho
#    + dominio.com = Nome     -> idem, e conta o tempo com esse nome
#    - sub.dominio.com        -> barra um subdomínio de um domínio liberado
#    ~ dominio.com            -> liberado, mas NÃO conta como estudo (música)
#    # texto                  -> comentário (é ignorado)
#
#  Liberar "exemplo.com" também libera todos os subdomínios,
#  como "pt.exemplo.com" e "www.exemplo.com".
#  Não são aceitos curingas (*) nem sufixos públicos como "com.br",
#  que liberariam milhares de sites.
# ================================================================
